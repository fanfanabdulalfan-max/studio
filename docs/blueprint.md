# **App Name**: KasMahasiswa Pro

## Core Features:

- Financial Overview Dashboard: Visual cards displaying current balance, total income, and total expenses extracted from transaction data.
- Member Ledger Management: Comprehensive student directory to add, edit, and delete student records with unique IDs.
- Smart Weekly Contribution Tracker: An interactive grid for tracking weekly payments with automatic calculation for specific fee increments (e.g., Rp 5,000).
- Expenditure Logging System: A digital form to record class spending with descriptions, timestamps, and amounts stored locally.
- CSV Reporting Tool: Functionality to aggregate local payment data into a downloadable CSV report for full transparency.
- AI Treasury Assistant: An AI tool that uses class transaction history to summarize monthly trends and recommend future budget adjustments.
- Unified Data Filter: Real-time search bar and filters to quickly find specific students or verify payment statuses.

## Style Guidelines:

- Primary Color: Deep Navy (#1A365D), reflecting professional authority and trust. Background: Very light tint of slate (#F1F5F9) to provide a clean, modern canvas for data.
- Accent Color: Vibrant Teal (#0D9488) used for 'Paid' status buttons and action-oriented Call to Actions.
- The font 'Inter' is recommended for its machined, objective look, ensuring maximum legibility for financial data across all screen sizes.
- Consistent use of 'Lucide React' stroke icons to keep the interface lightweight and visually intuitive for navigation.
- Mobile-first responsive design with a side-navigation on desktop and a sticky bottom-tab bar for key features on mobile devices.
- Subtle entry transitions for list items and smooth layout morphing when expanding the dashboard statistics.
